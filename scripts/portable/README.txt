劳动争议证据整理器 —— Windows 绿色便携版
================================================

一、这是什么
------------
本地单机版，所有数据（数据库、上传文件）都保存在本程序文件夹内。

本程序有两种发行形式，内容完全相同，任选其一：
- 绿色便携版（zip）：解压到任意文件夹，双击文件夹里的 start.bat
- 一键安装版（setup.exe）：运行安装向导，可自选安装目录，
  装完从开始菜单 / 桌面图标启动

二、系统要求
------------
- Windows 10 / 11（64 位）
- 无需安装 Python、Node.js、数据库，全部已内置
- 首次启动需联网吗？不需要。所有功能均可离线使用（AI 生成除外，见第五节）

三、如何启动
------------
1. 双击 start.bat
2. 等待约 5 秒，浏览器自动打开 http://127.0.0.1:3000
   （没自动打开就手动访问该地址）
3. 第一次使用请点「注册」创建自己的账号（邮箱 + 密码，密码至少 8 位）
4. 使用完毕后，双击 stop.bat 关闭程序

也可以把 start.bat 发送到桌面快捷方式，日常使用更方便。

四、数据在哪
------------
- 数据库：data\leo.db
- 上传的材料：data\storage\
- 重要数据请定期备份整个 data 文件夹
- 想重置为全新状态：关闭程序后，删除 data 文件夹再启动
  （data 位于程序安装/解压的文件夹内）

五、可选：接入自己的 AI（用于分析证据、生成案件叙述）
------------
默认使用离线模拟模式（不联网、内容为演示数据）。
若要使用真实 AI：

1. 用记事本打开 backend\.env
2. 修改以下几行（去掉行首 # 号）并填入你的信息：

   AI_PROVIDER=openai
   AI_BASE_URL=https://api.openai.com/v1
   AI_API_KEY=你的API密钥
   AI_MODEL=gpt-4o-mini

3. 保存后运行 stop.bat，再运行 start.bat

说明：支持任何 OpenAI 兼容接口（如各大厂商的 API 中转/代理服务）。
AI 密钥只保存在本机 .env 文件中，不会上传。

六、卸载 / 删除
------------
- 一键安装版：开始菜单或 Windows 设置 → 应用 → 卸载
  （卸载前会提醒备份，将一并删除数据）
- 绿色便携版：运行文件夹里的 stop.bat 后直接删除整个文件夹

七、常见问题
------------
1. 端口被占用（启动后浏览器打不开）
   - 8000 或 3000 端口被其他程序占用时启动会失败
   - 关闭占用这些端口的程序，或参阅技术文档修改端口

2. Windows SmartScreen / 杀毒软件提示
   - 脚本和内置运行时均为开源官方组件，选择「仍要运行」即可
   - 首次运行请右键 start.bat → 属性 → 若有「解除锁定」请勾选

3. 换电脑 / 搬迁
   - 直接整个文件夹拷贝到新电脑即可，无需重新安装

4. 仅限本机使用
   - 本版本按单机使用设计，服务只监听 127.0.0.1（本机）
   - 局域网共享访问不在支持范围内
