# 用户故事与验收标准

## Epic A：案件

A-01 创建案件
A-02 修改案件
A-03 删除案件
A-04 查看案件

## Epic B：资料

B-01 批量上传
B-02 文件预览
B-03 文件删除（软删除）
B-04 查看处理状态
B-05 失败重试

## Epic C：AI

C-01 分类
C-02 OCR/文本提取
C-03 日期提取
C-04 金额提取
C-05 人物/组织提取
C-06 事件提取
C-07 摘要
C-08 证明目的建议
C-09 置信度

## Epic D：人工审核

D-01 修改字段
D-02 确认证据
D-03 忽略建议
D-04 重新分析
D-05 查看原始文件

## Epic E：案件结构

E-01 时间轴
E-02 证据目录
E-03 证据与事件关联
E-04 证据与事实关联

## Epic F：导出

F-01 DOCX
F-02 PDF
F-03 ZIP
F-04 自动页码
F-05 证据编号

## Definition of Done

每个功能必须：
- 有类型定义；
- 有错误处理；
- 有测试；
- 有 loading/empty/error 状态；
- 不破坏原始文件；
- 更新相关文档。
